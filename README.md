# You Need It

A responsive landing page for an unusual auction featuring works that were once underestimated but later became iconic.

## Technologies

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Responsive Design
- Semantic HTML

## Features

- Responsive layout
- Auction lot cards
- Navigation between page sections
- Image overlays
- Accessible semantic markup
